# Productization Roadmap

## Stage gates

| Gate | Objective | Minimum evidence |
|---|---|---|
| G0 — Concept | Define public value and user problem | Product brief, sponsor hypothesis, excluded decisions |
| G1 — Discovery | Confirm process, users, controls and data | Process map, service blueprint, data inventory, risk screen |
| G2 — Design | Approve architecture and governance | PRD, architecture decision records, control matrix, evaluation plan |
| G3 — MVP | Demonstrate an end-to-end controlled workflow | Executable slice, synthetic data, tests, human-review checkpoints |
| G4 — Pilot | Validate value, usability, security and accuracy | UAT, security testing, model evaluation, operating procedures |
| G5 — Production | Establish accountable operation | Support model, monitoring, change control, incident response, approvals |
| G6 — Scale | Replicate and optimize benefits | Benefits realization, adoption, cost, performance and maturity evidence |

## Portfolio waves

### Wave 1 — Shared foundation

- Product registry and common API.
- Identity and role model.
- Evidence provenance and citation schema.
- Human approval and segregation-of-duties controls.
- Audit log, evaluation harness, redaction and secret scanning.

### Wave 2 — Priority MVPs

1. AI Use Case Assessor.
2. Strategic Radar and Signal Detection.
3. Process Audit AI.
4. Service Design AI.
5. Corporate Performance Review AI.

### Wave 3 — PFM intelligence

1. PFM Brain.
2. PFM Agentic AI.
3. IPSAS Compliance AI.
4. Revenue Reconciliation AI.
5. PFM Cycle-Time Benchmark.
6. PFM Maturity & Certification.

### Wave 4 — Enterprise operating system

1. Enterprise Process Intelligence.
2. Enterprise Architecture Intelligence.
3. Partnership Management Copilot.
4. AI Governance Control Tower.
5. Integrated IT Management AI.

## Cross-product definition of done

- Traceable requirements and acceptance criteria.
- Synthetic demo data and data dictionary.
- Security threat model and privacy assessment.
- Responsible-AI risk assessment.
- Model and prompt evaluation with defined thresholds.
- Human-review and escalation rules.
- Automated tests, deployment instructions and monitoring.
- Benefits, cost and performance measures.
- Operating procedures and change-control ownership.
