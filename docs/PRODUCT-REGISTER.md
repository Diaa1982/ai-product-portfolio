## Status interpretation

- **Available:** prior framework, configuration, prototype, workbook, blueprint, or methodology exists.
- **Baseline:** this repository contains a sanitized product package and backlog.
- **MVP:** executable product slice with synthetic data.
- **Pilot:** controlled user testing with approved non-production data.
- **Production:** security, governance, support and operational-readiness gates passed.

No baseline status implies production readiness or institutional approval.
