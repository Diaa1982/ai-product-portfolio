# Rapid Website Launch Plan

## Goal
Launch the company website within a few days with a professional market-facing presence and a clean path to the future platform.

## Immediate sequence
1. Lock working company/brand name and domain candidate.
2. Confirm homepage copy and solution taxonomy.
3. Select implementation stack and hosting.
4. Set visual direction and design tokens.
5. Build homepage skeleton and global components.
6. Add solution/platform/about/contact pages.
7. Deploy staging, QA mobile/forms/SEO/accessibility, then production.

## Must launch
- Homepage
- Solutions hub and reusable solution template
- AI Platform overview
- Government/Public Sector industry page
- About
- Contact and demo forms
- Privacy/Terms production placeholders requiring final legal review
- Analytics and SEO metadata
- Mobile responsive design
- Production deployment

## Strongly preferred
- Assessment Center landing
- Transformation Readiness assessment teaser or functional first version
- Insights landing with 2–3 foundational articles

## Immediately after launch
- Full CMS
- Additional industry pages
- Complete assessment engine
- Account/workspace
- Evidence upload
- AI diagnostics

## Fast delivery rule
Use a modern component-based web stack with static/server-rendered public pages and minimal backend requirements for launch. Keep assessment and platform services modular.

## CTA hierarchy
1. Start Assessment
2. Explore Platform
3. Talk to an Expert

If the assessment is not production-ready on launch day, Start Assessment must lead to a legitimate assessment intake/waitlist, never a broken workflow.

## Go-live gate
- Domain + TLS
- Mobile QA
- Broken-link check
- Forms tested
- Analytics tested
- SEO/OG metadata
- Sitemap/robots
- Accessibility smoke test
- No unsupported customer claims/fabricated metrics
- Privacy/consent messaging
- Error monitoring
- Rollback capability
