## V2 — Manage & Transform
Enterprise knowledge model; agent registry/orchestration; client workspace; action management; reassessment/trends; integrations.

## V1 release gate
An external visitor can discover the company, understand the proposition, select a problem, complete a governed Transformation Readiness Assessment, receive reproducible results and request a commercial next step.

## V1.5 release gate
A registered organization can complete an assessment, upload evidence, receive traceable AI-assisted findings/recommendations, have them reviewed by a human and produce a controlled executive report.

## Definition of Done
Implemented, reviewed, tested, responsive, accessible, secured, observable/analytics-ready, documented and deployed to staging. AI stories additionally require traceability, execution/version metadata, human accountability and explicit uncertainty handling.
