## Documentation control

- GitHub changes use branches, pull requests, automated checks, and traceable commits.
- Notion pages summarize the current approved management position and link to GitHub rather than duplicating executable source.
- The control center records operating status and evidence references; it does not issue approvals.
- Product IDs P01-P18 and repository slugs are stable identifiers across all three platforms.
- Update Notion after a GitHub release or formal lifecycle decision, recording the review date and accountable owner.
- Never copy confidential evidence into public or uncontrolled locations. Use sanitized references to an approved evidence repository.

## Review cycle

Review the portfolio at each stage-gate decision and at least quarterly during pilot and operation. Confirm ownership, evidence currency, risk status, KPI baselines and actuals, control effectiveness, incidents, changes, benefits, and retirement criteria.
