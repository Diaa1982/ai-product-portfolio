# Go-Live Checklist

## Gate 1 — Business/KPI
- [ ] Business owner approved
- [ ] KPI owners assigned
- [ ] Definitions/targets approved
- [ ] Reporting calendar approved

## Gate 2 — Data
- [ ] Source systems and lineage approved
- [ ] Quality thresholds defined
- [ ] Reconciliation tested
- [ ] Sensitive-data handling approved

## Gate 3 — Process/Controls
- [ ] Process owners confirmed
- [ ] Approval matrix and SoD validated
- [ ] Action closure rules approved
- [ ] Audit requirements validated

## Gate 4 — Technology
- [ ] BI/CRM/ERP adapters tested as applicable
- [ ] Authentication/authorization tested
- [ ] Logging/monitoring active

## Gate 5 — Analytical Validation
- [ ] KPI calculations reconciled
- [ ] Management reports validated
- [ ] Root-cause and data-quality workflows tested

## Gate 6 — UAT/Operations
- [ ] Global/regional UAT completed
- [ ] Operations/support owners assigned
- [ ] Training completed
- [ ] Incident/rollback tested

## Gate 7 — Authorization
- [ ] Residual risks accepted
- [ ] Pilot reviewed
- [ ] Production scope approved
- [ ] Formal go-live authorization obtained
