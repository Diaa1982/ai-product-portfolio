# KPI Framework

Every KPI must have: name, acronym, purpose, definition, formula, numerator/denominator, unit, inclusion/exclusion rules, aggregation method, source, owner, target, tolerance, refresh frequency, drill-down dimensions, data-quality status, version and effective date.

## KPI families
Commercial: Order Entry, Revenue, Hit Rate, Backlog, Forecast Accuracy.
Operational: OTD, Lead Time, Schedule Adherence, First-Time-Right.
Quality: QRT, repeat issue rate, corrective-action closure.
Customer: feedback, complaint, response and resolution measures.
Data/Process: CRM completeness, dashboard freshness, process compliance.

Where systems disagree, reconcile definition, date logic, status, currency, timezone, exclusions, duplicate handling and refresh timing before comparing.
