# Dashboard Standard

A dashboard must answer a management question rather than display available data.

Required elements:
1. executive status
2. target vs actual
3. trend
4. exceptions
5. drill-down
6. drivers/root causes
7. actions
8. owners/due dates
9. data freshness
10. metric-definition reference

Recommended products: Global Service Scorecard, Regional Performance, Commercial Performance, Delivery Reliability, Quality Performance, Lead-Time Decomposition, Customer Feedback, Corrective Action Tracker, CRM Data Quality and Digitalization Pipeline.
