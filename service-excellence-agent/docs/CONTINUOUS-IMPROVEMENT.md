# Continuous Improvement Method

Cycle:
Define problem → baseline → stratify → map process → identify causes → validate causes → select countermeasures → assign actions → implement → verify effectiveness → standardize → close.

Use Pareto for concentration, 5 Whys for causal chains, Ishikawa for cause categories, SIPOC for scope/interfaces, process maps for handoffs/waste, value-stream analysis for delay and control plans for sustainment.

A corrective action is not complete until effectiveness is evidenced against explicit closure criteria.
