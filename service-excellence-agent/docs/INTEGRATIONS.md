# Integration Guide

## Power BI
Consume governed semantic models, reuse certified measures and inspect refresh status. Official publication follows approved workspace/report processes.

## Tableau
Use approved data sources and preserve row-level security and controlled definitions.

## Excel
Use as an analytical/reporting tool unless formally designated as controlled. Prefer tables/named ranges, protected formulas and clear data-source references.

## Salesforce/SFDC and CRM
Read-only by default. Production write-back is approval-controlled.

## ERP / Finance
Revenue and order values must use approved financial/commercial definitions.

## Supply Chain / Manufacturing
Use for delivery constraints, material availability, production milestones, schedule adherence and lead-time drivers. Planning/execution changes require authorized owners.

## Agent-to-Agent
Use the A2A schema with objective, evidence, scope, constraints, priority and expected output.
