# Data Quality Standard

Assess completeness, accuracy, consistency, validity, uniqueness, timeliness, lineage and reconciliation.

Material defects should record source system, object/table, field/measure, defect type, affected population, business impact, suspected cause, owner, remediation, prevention control, target date and verification evidence.

For Salesforce/CRM, common checks include missing mandatory fields, stale close dates, duplicate accounts/opportunities, invalid ownership, order/opportunity mismatches, missing win/loss reason, forecast-category inconsistency and product hierarchy mismatch.
