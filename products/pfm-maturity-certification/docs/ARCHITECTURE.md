# Architecture

P18 uses FastAPI, deterministic assessment rules, versioned JSON configuration, synthetic fixtures and the shared audit platform. Inputs are criteria results, evidence, assessor identities, performance history, external comparisons and moderation controls. Outputs are evidenced maturity, domain scores, conformance, QA, recognition-readiness, surveillance and improvements.

No accreditation, assessor identity, evidence repository, KPI or architecture-system connector is implemented. Production adapters require approved APIs, immutable lineage and least privilege.
