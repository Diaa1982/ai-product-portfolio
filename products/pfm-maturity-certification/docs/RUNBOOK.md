# Runbook

1. Verify health and active criteria/configuration version.
2. Confirm assessment mode, scope, assessor independence and evidence freeze.
3. Resolve evidence/conformance QA before moderation.
4. Preserve input, configuration and digest for disputes or appeals.
5. Stop publication if authority, conflicts, evidence or scheme status is uncertain.
6. Roll back to the last approved release and escalate all recognition/certification decisions.
