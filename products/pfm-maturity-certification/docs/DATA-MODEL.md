# Data model

The assessment contains identity/profile/date/mode/scope, criteria, evidence, assessors, performance history, external comparisons, moderation and assumptions. Outputs contain evidenced overall/domain maturity, conformance, QA, moderation, candidate recognition, surveillance, improvements, digest and limitations.

Production needs canonical criterion/evidence IDs, immutable versions, digital signatures, identity assurance, classifications, lineage, retention and lawful access.
