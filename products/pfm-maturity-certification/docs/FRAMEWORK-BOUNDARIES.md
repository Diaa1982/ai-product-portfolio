# Framework boundaries

G-APFM/GAPFS content is a principles-based working draft and is not an adopted international standard. P18 may map evidence to locally approved reference frameworks, but does not replace statutory law, IPSAS, GFSM, PEFA, INTOSAI, COSO or other authoritative requirements.

No output is a compliance declaration, audit opinion, PEFA score, IPSAS conclusion or sovereign-accountability decision.
