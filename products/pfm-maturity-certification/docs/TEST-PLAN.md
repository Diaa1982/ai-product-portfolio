# Test plan

Fifteen focused tests cover levels/domains, evidenced overall maturity, domain completeness, formal-rating/certificate denial, candidate-only recognition, self-assessment limits, missing-evidence caps, level 4/5 gates, segregation, mandatory principles, surveillance and digest.

Production adds schema/property, inter-rater, calibration, security/privacy, accessibility, load, resilience, evidence-signature, appeal and independent conformance tests.
