# Benchmark methodology

Every value requires a cited source, exact start trigger, end point, unit and scope. Types are observed average, observed median, target SLA, statutory deadline, best-practice reference, PFM performance threshold and expert estimate.

Sequential steps may be summed only when consecutive. Parallel work uses the critical path. Mixed services use volume-weighted averages. Waiting and rework remain visible. Median is preferred for skewed cycle-time distributions; average is retained for transparency.

Gaps against deadlines/SLAs are threshold headroom or exceedance—not proof of process efficiency. Targets remain draft until approved.
