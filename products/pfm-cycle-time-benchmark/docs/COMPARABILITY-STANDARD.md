# Comparability standard

Comparability checks unit, start point, end point and scope profile; score is the proportion matched. Numeric comparison requires at least 0.75, a valid cited value, reliability A/B and a non-proxy match.

Exact means materially equivalent boundary and scope. Nearest requires a documented rationale. Proxy is directional only and cannot produce a numeric gap or target. No-data produces an unbenchmarked queue item.

Complexity, volume, control intensity, automation, legal deadlines, service criticality and jurisdiction must be reviewed before adoption.
