# Product roadmap

- Foundation: engine, source/benchmark schema, QA, UI, tests, docs and container — complete for synthetic use.
- Pilot preparation: approved source library, license review, event data contract, calendars, exclusions, bilingual terminology and UAT.
- Controlled pilot: read-only process-mining/workflow adapters, percentiles/trends, bottleneck drill-down, observability and security/performance testing.
- Production: L0–L10 evidence, residual-risk and formal go-live/publication approvals.
- Scale: sustained validation, benchmark refresh cycles and benefits measurement.
