# Reliability classification

- A: direct authoritative benchmark for a materially comparable process.
- B: official SLA, statutory deadline or PFM performance threshold.
- C: proxy for directional comparison only.
- D: no reliable public benchmark.

Class describes evidence suitability, not organizational performance. A/B still require boundary and context checks. PEFA PI-style calendar thresholds remain performance thresholds unless the methodology explicitly defines an operational transaction benchmark.
