# Data model

Process observations hold L1–L4 IDs/names, boundaries, scope, unit, samples, waiting, rework, priority, complexity and aggregation metadata. Benchmark records hold matched process, match rationale, type, reliability, value, boundary, source and applicability. The source library holds publisher/version/retrieval/license metadata.

Production event data requires canonical IDs, timestamp/time-zone rules, business-calendar treatment, pause/exclusion policy, owners, lineage, quality and privacy controls.
