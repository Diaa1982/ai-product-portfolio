# Architecture

P13 uses FastAPI, a deterministic assessment engine, versioned JSON configuration, synthetic fixtures and the shared case/audit platform. The metamodel connects outcomes → mandates → value streams → capabilities → processes/services → information/data → applications/integration → technology/AI/security/operations → KPIs/risks/controls.

The nine reference layers are business, information, data, application, integration, technology, AI, security and operations. Adapters to GRP, Hyperion, TMS, Bayan, Power BI, ALMAS or other systems are production backlog items; no connector is implemented or implied.
