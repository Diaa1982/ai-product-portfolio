# Runbook

1. Check `/health`, config version and storage.
2. Confirm approved IDs and evidence sources.
3. Resolve validation exceptions before interpreting results.
4. On divergence, preserve request/config/digest, stop publication and open an incident.
5. Roll back to the last approved image/config; do not edit scores manually.
6. Escalate mandate, policy, accounting, security and target-state questions.

No result authorizes a production architecture change.
