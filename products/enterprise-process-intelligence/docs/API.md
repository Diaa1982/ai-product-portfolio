# API
| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/p10` | Repository intelligence studio |
| GET | `/p10/config` | Controlled hierarchy/governance configuration |
| POST | `/p10/analyze` | Validate portfolio, traceability, maturity and migration readiness |
| POST | `/p10/changes/classify` | Route minor/moderate/major change |
| POST | `/p10/actions/check` | Enforce protected governance actions |

Use `synthetic/complete-process-portfolio.json`.
