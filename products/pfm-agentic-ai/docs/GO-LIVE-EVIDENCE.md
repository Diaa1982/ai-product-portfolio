# Go-Live Evidence Register

## Available in repository

- Versioned nine-agent configuration and protected-action catalogue.
- Deterministic calculation/orchestration module and twelve focused tests.
- API, command center, synthetic case, container definition and CI smoke-test design.
- Product, operating, governance, calculation, alignment, security, deployment, operations, test, UAT and roadmap documentation.

## Required before production

- Approved use-case scope, benefits, owners, RACI and organization-specific authority/delegation mapping.
- Approved data dictionary, authoritative sources, interfaces, quality/reconciliation evidence and retention.
- SSO/RBAC/segregation, security/privacy/legal review, threat model, penetration test and incident exercise.
- Persistent tamper-evident audit/evidence store, monitoring, backup/restore and rollback evidence.
- Control-owner calculation validation; accounting-policy and applicable PEFA/IPSAS mapping.
- UAT and limited-pilot results, training/support readiness, residual-risk acceptance and formal go-live decision.

Until those items are approved, the correct status is **technical deployment candidate using synthetic data only**.
