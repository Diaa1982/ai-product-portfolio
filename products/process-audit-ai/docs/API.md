# API

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/p06` | Bilingual audit studio |
| GET | `/p06/config` | Controlled domains, criteria, ratings and gates |
| POST | `/p06/audit` | Execute evidence and scoring assessment |
| POST | `/p06/capa/verify` | Evaluate independent CAPA verification readiness |
| POST | `/p06/dashboard` | Aggregate division assurance indicators |
| POST | `/p06/actions/check` | Enforce human-only assurance decisions |

Use `synthetic/complete-process-audit.json`. OpenAPI is at `/docs`.
