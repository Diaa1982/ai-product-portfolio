# Audit methodology

P06 follows Plan → Audit → Evidence → Assess → Find → Correct → Verify → Update → Monitor → Improve. Its four lenses are conformance, control, effectiveness and improvement. Methods include document review, interview, walkthrough, observation, transaction sampling, reperformance/recalculation, system/log review, end-to-end trace, root-cause analysis and trend analysis.

The methodology draws on ISO 9001 process-based management, risk-based thinking and PDCA; ISO 19011 auditing guidance; internal-control practice; root-cause/CAPA methods; and DGEP Process Management. These are alignment references requiring local validation, not automatic compliance or certification.
