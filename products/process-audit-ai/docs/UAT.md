# User acceptance testing

Authorized process-governance, quality, audit and division users execute representative critical/non-critical processes. They validate English/Arabic criteria, RTL/accessibility, criterion applicability, evidence triangulation, sampling, documented-versus-actual comparison, scores, finding drafts, override reasons, CAPA verification, division filters/reports and role segregation. Acceptance requires signed methodology/criterion approval, findings/defects, residual risks and deployment recommendation. Synthetic developer tests are not UAT or audit evidence.
