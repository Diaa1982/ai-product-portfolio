# Governance and roles

Roles include system administrator, EPM administrator, lead auditor, auditor/team, process owner, action owner, independent verifier, governance/quality reviewer and leadership. Key segregation rules are auditor ≠ process owner and action owner ≠ CAPA verifier. Auditor overrides of AI suggestions require recorded reasons.

The process-governance operating model should connect Division Champion initiation, process-owner validation, Division Manager authority, control-unit review, process designer updates and Strategy/Corporate Performance publication authority according to the organization’s approved workflow. P06 does not replace formal Internal Audit authority.
