# Data model

Core objects: ProcessRegisterEntry, ProcessVersion, AuditProgramme, AuditPlan, CriterionVersion, EvidenceItem, TransactionSample, CriterionAssessment, AISuggestion, AuditorDecision, Finding, RootCause, CorrectiveAction, EffectivenessVerification, ProcessUpdateRequest, Approval, DashboardSnapshot and AuditEvent. Stable IDs and append-only version/decision history are required. Every report records configuration, evidence and transaction hashes.
