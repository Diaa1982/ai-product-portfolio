# Documented-versus-actual testing

Compare the current approved process version with actual execution using sampled transactions, interviews, walkthroughs, observation, system evidence, logs, approvals, records and audit trails. Test sequence, control operation, authorized approval, inputs/outputs, role consistency, workarounds/exceptions, timestamps and cross-unit consistency. Report documented steps missing in practice and actual steps not approved/documented. Sampling scope and representativeness remain auditor decisions.
