# Security and Privacy

Baseline controls include source class/domain allowlists, complete provenance and exact-citation requirements, hash validation, manual-creation restriction, deterministic scoring, human high-impact approval, synthetic-only data, non-root container and no external model dependency.

Production requires SSO/RBAC and segregation, egress proxy, SSRF/redirect/domain-takeover defenses, secure fetch/OCR sandbox, malicious-content/prompt-injection controls, encryption and managed secrets, immutable evidence/audit stores, WAF/rate limits, SBOM/scanning/signing, privacy/legal/licensing review and security monitoring/incident response.

No agent may approve transfers, payments, signatures, certifications, fiscal adjustments or external publication.
