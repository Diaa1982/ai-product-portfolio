# Operations Runbook

Monitor source freshness/outages, version gaps, fetch/OCR errors, blocked/partial/conflicting evidence, citation coverage, materiality/confidence distributions, queue aging, false positives, missed changes, approvals, delivery and audit integrity.

P1: unauthorized high-impact publication, evidence/audit loss, source compromise or sensitive-data exposure—halt affected ingestion/delivery and activate incident command. P2: material scoring/extraction degradation—freeze queue promotion, revert release/config and route to manual review. P3: isolated interface/report issue—normal change control.

Source owner, analyst lead, PFM subject owner, strategy/risk authority, platform, data and security roles require named target owners, escalation contacts, SLO/SLA and RTO/RPO before production.
