# Product Requirements Document

## Outcome

Identify material changes early, preserve an audit-grade evidence chain and route candidate signals to accountable analysts with low false-positive executive exposure.

## Scope

Approved-source ingestion contract; current/prior version comparison; evidence validation; signal category, PFM focus, materiality and confidence; conflict/partial handling; analyst queue; high-impact approval; business/government output hypotheses; feed to Strategic Radar.

## Signal categories

Regulatory/licensing; public spending/incentives/funding; macro/sector indicators; tenders/procurement/infrastructure/investment; trade/customs/tax/tariff/subsidy/market access; labor/skills; digital mandates; environmental rules; filings/capital disclosures.

## Acceptance

Unsupported sources or missing exact citations are blocked; unchanged source versions produce no signal; ordinary manual creation is blocked; null/conflict/partial evidence routes to review; ≥0.82 never auto-publishes; high-impact publication requires authorized human approval; every conclusion layer remains traceable.
