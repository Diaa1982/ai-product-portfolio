# Data Model

Input records contain detection context, audience/category/PFM focus, affected entities/effective date, source and version provenance, citations, evidence quality, materiality/confidence criteria, separated analytical layers and high-impact flag.

Result records contain signal ID/time, detection/evidence status and issues, materiality/confidence, review route, publication state, approval requirement/role, analytical layers and full evidence reference.

Production adds raw/normalized artifact identifiers, extraction spans, model/prompt/rule versions, authenticated actor, review/approval events, delivery receipts, feedback labels and retention/legal-hold metadata.
