# User Acceptance Testing

Use the controlled synthetic pack or formally approved masked data. Reconcile every calculation to `Expected_Result`.

| Scenario | Expected result |
|---|---|
| Full load sequence | Ready only after all nine domains load in order |
| Revised budget/closing cash | Exact formula and reconciliation within AED 0.01 |
| Duplicate, missing evidence or invalid reference | Blocked and traceable issue |
| Revenue shortfall/cash buffer/KPI direction | Correct calculation, status, risk and recommendation |
| Control and residual risk | Effective/Partial/Failed and risk band match approved rules |
| Authority and SoD | No automatic approval; conflict/limit breach blocked |
| AED 420M rephase or protected action | Critical risk and human approval interruption |
| Report mismatch | Blocked; reconciliation status `Mismatch` |
| Valid snapshot | Facts, calculations, risks, assumptions, recommendations and digest present |

Sign-off requires product and PFM process owners, data owners, technology operations, security/privacy, internal control and relevant budget/treasury/revenue/performance/accounting reviewers. UAT does not grant statutory or delegated authority.
