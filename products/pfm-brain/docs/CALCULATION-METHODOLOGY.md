# Calculation Methodology

| Measure | Formula/rule |
|---|---|
| Revised budget | Original + Supplementary + Transfer |
| Available budget | Revised budget − Actual expenditure − Commitments |
| Budget variance | Actual expenditure − Period plan |
| Revenue shortfall | max(0, Revenue target − Revenue actual) |
| Closing cash | Opening cash + Inflow − Outflow |
| Cash buffer gap | Closing cash − Minimum cash buffer |
| KPI Higher | On Target at/above target; Attention within approved percentage below; otherwise Off Target |
| KPI Lower | On Target at/below target; Attention within approved percentage above; otherwise Off Target |
| Control result | Effective ≥80%; Partially Effective ≥50% and <80%; Failed <50% |
| Residual risk score | Inherent risk × (1 − control effectiveness/100) |
| Residual risk band | High ≥70; Medium ≥40; Low <40 |

Revised budget and closing cash reconcile to provided expected results using a default AED 0.01 tolerance. These thresholds are synthetic MVP rules, not legislation, accounting standards or delegated authority. Production owners must approve basis, sign convention, rounding, materiality, period, currency, consolidation, exceptions and formula version.
