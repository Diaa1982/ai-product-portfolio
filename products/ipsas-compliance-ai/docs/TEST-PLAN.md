# Test Plan

Fifteen focused tests cover disabled formal determination, clean journal review, balance, cut-off, evidence, approval, SoD, material/reporting impact, confidence, policy/requirement references, reconciliation/aging/evidence, disclosure/comparatives, protected actions and separated audit output.

CI runs all repository tests, registry validation, compilation, secret-file checks, container build and live P11 review/action-control smoke tests.

Before pilot, assemble representative end-to-end source files, known exceptions and expert ground truth. Validate 100% supported-sample processing and at least 90% key-field/test-set agreement, plus false-positive/negative, citation, security, performance, resilience, accessibility, backup/restore and UAT evidence. Accounting experts approve evaluation criteria and residual error tolerance.
