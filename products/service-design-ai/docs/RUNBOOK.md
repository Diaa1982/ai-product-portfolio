# Runbook

Monitor availability, latency, validation errors, blocked gates, evidence failures, action denials, configuration drift and audit-write health. On integrity, authorization, data or unsafe-output concern: stop processing, preserve logs/evidence, notify product/security/service owners, classify impact, apply the approved workaround or rollback, validate recovery with synthetic cases, and record closure. Never bypass a gate to restore service. Methodology/config changes require versioning, regression tests and owner approval.
