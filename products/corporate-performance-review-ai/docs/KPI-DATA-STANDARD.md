# KPI Data Standard

Master fields include KPI ID/name, strategic objective, perspective, organization level, sector/division, KPI/data owners, frequency, unit, direction, baseline, target, weight, formula, aggregation, tolerance, source and effective dates.

Result fields include KPI ID, period, actual, target, forecast, evidence reference, owner comment, root cause, existing action, data status and approval date.

Rules: permanent KPI IDs; one KPI-period row; consistent number/percentage convention; approved frequency/direction/aggregation; master/result target reconciliation; evidence and approval for official results; source-row hash and data cut-off; no invented mappings or missing values. Production uploads require schema, duplicate, referential, period, type, range and file-malware validation.
