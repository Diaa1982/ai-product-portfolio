# Data Model

Input contains KPI master, period result, source-row hash, data cut-off, prior actual, narrative layers, corrective actions, target treatment/proposal, review schedule and executive flag.

Result contains review/KPI IDs, data-quality status/issues, score/status/variance/trend, calendar status, separated narratives, actions, target-treatment status, approval route and source reference.

Production adds workbook/file ID/hash, normalized row ID, formula/config version, data lineage, authenticated actors, validation history, approval/evidence events, action status/escalation, report version and retention/legal hold.
