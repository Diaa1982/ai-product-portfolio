# Security and Privacy

Baseline controls include schema/domain validation, official-result evidence requirements, immutable source hash, separated narratives, unapproved-target label, human decisions, synthetic-only data and unprivileged container.

Production requires SSO/RBAC/segregation; controlled file upload and malware/formula injection scanning; encryption and managed secrets; immutable source/audit/version storage; least privilege; data minimization/retention; validation against unauthorized result/target changes; WAF/rate limits; dependency/container scanning/signing; privacy/security testing and incident response.

KPI owners cannot silently modify source data through the review interface; changes must return to the authoritative performance process.
