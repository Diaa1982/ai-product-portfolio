# Data Model

Use-case profiles capture identity, purpose, owners, classification, autonomy/consequence/sensitivity/scale/public flags and evidence. Risk results capture tier, block status, reasons, controls and roles. Gate records capture required/evidenced controls, conditions, approvers, status and next gate. Monitoring events capture metrics, severity, controls triggered, pause/shutdown action and incident owner requirement.

Production adds immutable actor identity, config/rule/model versions, evidence hashes, signatures, linked register records, decision history, exceptions, CAPA, delivery/deployment references and retention/legal hold.
