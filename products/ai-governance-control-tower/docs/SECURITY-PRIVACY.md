# Security and Privacy

Baseline controls: bounded inputs, fixed risk/gate configuration, cumulative control evidence, blocked financial actions, human-only decisions, QA/independent-test requirements, threshold incidents, safe shutdown, synthetic-only data and unprivileged container.

Production requires SSO/RBAC/segregation; step-up authentication and digital approval evidence; encryption and managed secrets; immutable audit/evidence; least privilege; data minimization/retention; WAF/rate limits; prompt/model/tool supply-chain controls; vulnerability/red-team/penetration tests; signed artifacts; vendor assurance; privacy impact assessment; incident notification and recovery.

Role spoofing, control-evidence substitution, configuration tampering, approval bypass and audit loss must fail closed.
