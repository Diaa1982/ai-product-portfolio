# Control, Risk and Governance Matrix

| Risk | Embedded control | Production accountability/evidence |
|---|---|---|
| Wrong form/rate/rule | Controlled forms/types/config version | Agreement, tax/policy and rule-owner approval/effective dates |
| Incorrect calculation | Deterministic formulas and expected-result reconciliation | Independent control-owner reconciliation |
| Missing/duplicate transaction | Required evidence and duplicate flags | Source completeness/uniqueness controls |
| False match | Reference and amount classification | Reviewer confirmation; model evaluation if probabilistic matching added |
| Unexplained discount/variance | Explicit exception and evidence route | Provider/agreement/bank evidence and owner decision |
| SoD/authority breach | Separate preparer/approver and protected actions | IAM, delegation and workflow enforcement |
| Unauthorized refund/tax/transfer | Autonomous-action denial | Revenue/tax/treasury/accounting authority records |
| Unclosed exception | Human decision and closure evidence requirement | Exception owner, SLA and independent review |
| Data/privacy/security incident | Synthetic baseline and security standard | Classification, encryption, monitoring and incident evidence |

The system provides reconciliation support; it does not establish legal entitlement, fraud, tax eligibility, accounting treatment or payment authority.
