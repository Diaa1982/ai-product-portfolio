# Security and Privacy

The MVP uses dummy/sample data. Do not submit live bank accounts, transaction details, taxpayer/provider information, credentials or confidential financial evidence.

Production requires classification/minimization and privacy/legal basis; SSO/MFA; least privilege and SoD; bank-account masking/tokenization; encryption; managed secrets; secure Excel/PDF intake and malware scanning; network segmentation; immutable source/evidence/decision/access logs; retention; vulnerability/penetration tests; monitoring; backup/DR and incident/continuity exercises.

Probabilistic matching, extraction or generative assistance requires approved training/evaluation data, confidence gates, explainability, false-match controls, prompt/tool security and human confirmation.
