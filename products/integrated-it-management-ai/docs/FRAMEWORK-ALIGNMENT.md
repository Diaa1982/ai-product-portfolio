# Framework Alignment

P16 uses ITIL 4 for service-management concepts, COBIT for governance/management objectives, ISO 20000 for service controls, ISO 27001 for security controls, ISO 22301 for continuity, ISO 31000 for risk, TOGAF for architecture and PMBOK for project/portfolio terminology. It is an integrative management layer, not a substitute for any framework and does not claim conformity, compliance or certification. The organization must map applicable clauses/practices, appoint owners, retain evidence and obtain independent assurance where required.
