# Source Governance

Every production source requires an owner, official status, approval decision, active period, permitted domains, jurisdictions/topics, retrieval method, licensing/use terms, classification, quality/reliability review, refresh frequency, retention and escalation contact.

Workflow: propose → due diligence → owner/control approval → activate → monitor → suspend/retire. Source content never becomes trusted solely because an AI system retrieved it.

For each retrieval preserve URL, source ID/version, publication and retrieval times, raw-content hash, prior-version link, extraction method and change summary. Redirects or domain changes require reapproval. OCR uncertainty, inaccessible content, contradictory official publications and missing versions route to review and block high-impact delivery.

The included `SYN-OFFICIAL-001` source is a simulation for CI and demonstrations; it is not a real production authority.
