# Enterprise metamodel

Element types cover strategy outcome, law/policy, standard, capability, organization unit, role, stakeholder, process, service, form, KPI, risk, control, application, interface, data object, database and technology.

Relationships include supports, governs, owns, performs, realizes, serves, measures, mitigates, controls, uses, produces, consumes, integrates with, stores, runs on, depends on and replaces. Each object and relationship has a stable ID, owner, lifecycle, evidence and version.
