# Product roadmap

- Foundation: graph engine, metamodel, QA, impact, portfolio, ADR, UI, tests and container — complete for synthetic use.
- Pilot preparation: conventions, canonical IDs, roles, data contract, bilingual terminology and representative repository export.
- Controlled pilot: read-only ARIS/BIC or other repository adapter, ERP/performance/risk/HR integrations, model comparison and UAT.
- Production decision: security/cloud/data/migration/exit evidence, operations, residual risk and Design Authority approval.
- Scale: process mining, change detection, KPI/risk synchronization and architecture-value tracking.
