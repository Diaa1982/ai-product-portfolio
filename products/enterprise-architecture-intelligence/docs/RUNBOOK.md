# Runbook

1. Verify health, configuration and repository snapshot/version.
2. Review ID, ownership, evidence, relationship and traceability exceptions.
3. Validate impact scope with element owners and domain architects.
4. Preserve input/config/digest for an ADR or incident.
5. Stop publication/migration on unresolved security, data or completeness gaps.
6. Roll back to the last approved snapshot and escalate decisions to Design Authority.
