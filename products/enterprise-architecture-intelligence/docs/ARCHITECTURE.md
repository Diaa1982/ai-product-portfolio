# Architecture

P15 uses FastAPI, a deterministic graph-analysis engine, versioned JSON configuration, a synthetic model and the shared audit platform. The runtime builds adjacency maps for traceability and impact analysis; it does not persist or mutate an enterprise repository.

The model is TOGAF-informed across Business Architecture, Data Architecture, Application Architecture and Technology Architecture, extended with integration, security and operations. Alignment does not establish formal TOGAF adoption or certification.
