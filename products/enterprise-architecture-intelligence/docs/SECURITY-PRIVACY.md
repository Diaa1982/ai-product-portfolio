# Security and privacy

The container is non-root, read-only and drops Linux capabilities. Production requires SSO/MFA/RBAC/PAM, segregation of duties, encryption, managed secrets/keys, secure interfaces, DLP, residency, SIEM, tamper-evident logs, vulnerability testing and incident response.

Architecture repositories expose sensitive dependencies, controls, data and technology risks; least privilege and need-to-know views are mandatory.
