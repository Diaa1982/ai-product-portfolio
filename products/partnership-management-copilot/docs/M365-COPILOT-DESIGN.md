# Microsoft 365 Copilot MVP design

Users invoke Copilot against approved SharePoint metadata and documents. Copilot returns structured drafts and citations for review. The first build excludes a separate orchestrator, autonomous orchestration, Power Automate approvals, background triggers and autonomous workflow. Access follows Microsoft 365 identity, permissions, sensitivity labels, DLP and audit controls. Prompts instruct Copilot to return insufficient evidence, preserve clause citations and never act as Legal or an approval authority.
