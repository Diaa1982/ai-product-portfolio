# Data model

Core objects are Partner, Partnership, AgreementVersion, AgreementItem, DocumentIndexEntry, EvidenceItem, UtilizationClaim, EvaluationCycle, CriterionAssessment, LifecycleAction, ChangeRequest, FirstReview, FinalDecision, NotificationDraft and CopilotReviewLog. Stable IDs, version history and append-only review records are required. Every analysis records configuration/source versions and a SHA-256 audit digest.
