# API

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/p07` | Bilingual partnership review studio |
| GET | `/p07/config` | Controlled statuses, registers, roles and policies |
| POST | `/p07/analyze` | Extract, assess evidence/utilization, monitor obligations/expiry and draft reports |
| POST | `/p07/changes/review` | Apply two-stage Strategy review rules |
| POST | `/p07/actions/check` | Enforce human-only legal/business actions |

Use `synthetic/complete-partnership.json`. OpenAPI is at `/docs`.
