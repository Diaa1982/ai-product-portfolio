# Register data standard

Partner_Master stores partner identity and approved contacts. Partnership_Register stores IDs, entity, responsible person/contact/email, dates, status, strategic/geographic classifications, initiative, innovation, expected value, objectives, notes and owner. One partnership can have many items; each stores type, deliverable/milestone, owner, counterparty, beneficiary, dates/recurrence, quantity/value, expected result, KPI/target, evidence type, dependencies and clause citation. All changes retain actor, time, reason, before/after values and approval reference.
